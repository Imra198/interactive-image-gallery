# interactive-image-gallery
A simple interactive image gallery built with HTML, CSS, and JavaScript that allows users to dynamically add and remove images using DOM manipulation and event handling.

Features
Add images dynamically using a URL
Remove images instantly with a button
Responsive gallery layout
Simple and clean user interface
Real-time DOM updates without page reload

 Technologies Used
 HTML5 – Structure of the web page
CSS3 – Styling and layout
JavaScript (Vanilla JS) – Functionality and interactivity

Project Structure
image-gallery/
│── index.html
│── styles.css
│── script.js

How It Works
User enters an image URL into the input field
Clicks the "Add Image" button
JavaScript:
Reads the input value
Creates new HTML elements (div, img, button)
Assigns the image source dynamically
Appends the elements to the gallery
Each image includes a Remove button
Clicking Remove deletes the image from the gallery

How to Run the Project
Clone or download this repository:
git clone https://github.com/Imra198/image-gallery.git
Open the project folder
Double-click index.html to open it in your browser
